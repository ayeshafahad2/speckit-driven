# Voice-to-Action: Using OpenAI Whisper

In this section, we will learn how to use OpenAI's Whisper model to convert spoken language into text, which can then be used to command our robot.

## Key Concepts

*   **Speech-to-Text**: Understand the fundamentals of automatic speech recognition (ASR) and how Whisper achieves state-of-the-art performance.
*   **Whisper API**: Learn how to use the Whisper API to transcribe audio files and real-time audio streams.
*   **ROS 2 Integration**: Integrate Whisper with ROS 2 to create a voice-controlled robotics application.
