# Capstone Project: The Autonomous Humanoid

This capstone project brings together all the concepts we've learned throughout this course. You will build an autonomous humanoid robot in simulation that can perform a complex task based on a natural language voice command.

## Project Goal

The goal of this project is to create a simulated humanoid robot that can:

1.  Receive a voice command (e.g., "Bring me the red ball").
2.  Use an LLM to plan a sequence of actions to accomplish the task.
3.  Navigate to the object's location, avoiding obstacles along the way.
4.  Identify the correct object using computer vision.
5.  Pick up the object and bring it back to the user.

## Key Skills

*   **ROS 2**: Develop a complete robotics application using ROS 2.
*   **Gazebo & Isaac Sim**: Create and use a simulated environment for testing your robot.
*   **Computer Vision**: Implement object recognition and tracking.
*   **LLMs & VLA**: Integrate a Large Language Model for cognitive planning and voice control.
*   **Humanoid Robotics**: Apply your knowledge of bipedal locomotion and manipulation.
