# Cognitive Planning: Using LLMs to Translate Natural Language

In this section, we will explore how to use Large Language Models (LLMs) to translate high-level natural language commands into a sequence of executable ROS 2 actions.

## Key Concepts

*   **LLMs for Robotics**: Understand the role of LLMs in robotics and how they can be used for task planning and decision-making.
*   **Prompt Engineering**: Learn how to design effective prompts to guide the LLM in generating the desired sequence of actions.
*   **ROS 2 Action Generation**: Develop a system that takes a natural language command (e.g., "Clean the room") and uses an LLM to generate a corresponding sequence of ROS 2 actions.
